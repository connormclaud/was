# Wholesome Assembly System (WAS)

> Some assembly required — but only 10 minutes of it.

An engineering methodology for home meal preparation. WAS treats lunch like a well-designed system: modular components, batch production, rapid assembly, and zero compromise on nutritional quality.

**The problem**: Cooking healthy meals daily takes too long. Meal prep guides either sacrifice nutrition for speed, or demand hours in the kitchen.

**The solution**: A control loop of two batch sessions per week (~90 min total) that produce interchangeable modules. Weekday "cooking" is just assembly — pick a protein base, a grain, and one component from each flavor axis. Done in under 10 minutes, every time.

Built with [Jekyll](https://jekyllrb.com/) and [Just the Docs](https://just-the-docs.com/). Deployed on [GitHub Pages](https://pages.github.com/).
