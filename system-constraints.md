# System Constraints

The system is designed for a physically active 40-year-old male, aligned with WHO dietary guidelines.

## Time Budget

| Context | Max Time |
|---------|----------|
| Weekday cooking (Mon–Fri) | ≤15 min/day |
| Weekday assembly (target) | ≤10 min/day |
| Sunday batch (Anchor A) | 45–60 min |
| Wednesday batch (Anchor B) | 40–45 min |

## Nutritional Targets

| Parameter | Target |
|-----------|--------|
| Energy intake | ~2500 kcal/day |
| Protein | 1.2–1.6 g/kg bodyweight |
| Fiber | ≥30 g/day |
| Salt | <5 g/day |
| Free sugars | <10% of total energy |

## Additional Guardrails

- **Protein distribution**: 30–45 g per main meal
- **Plant diversity**: ≥8 unique plant sources per day
- **Sodium control**: measured iodized salt, applied only at batch stage
- **AGE reduction**: rotate cooking methods (steaming, poaching, searing)
- **Polyphenols**: 85% dark chocolate, frozen berries in breakfast
